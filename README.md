## Project Introduction
This repository is dedicated to systematically tracking, organizing, and summarizing research results, open-source projects, and datasets related to **Multimodal Large Language Models (MLLMs)** and **Vision-Language-Action (VLA) models** in the field of Embodied Intelligence 📚.

## Core Categories

### 1. Embodied MLLMs 🧠

This section focuses on Multimodal Large Language Models integrated with embodied perception (e.g., vision, touch, kinesthesis), covering model architectures, pre-training strategies, downstream task adaptation, and other directions:
[[Awesome MLLMs for Embodied Intelligence]](Awesome-Embodied-MLLMs.md)

### 2. VLA 🤖

This section focuses on VLA models for embodied tasks (e.g., robot manipulation, environmental interaction), with a focus on research and projects related to end-to-end training, low-resource adaptation, and real-scenario deployment:
[[Awesome VLA for Embodied Intelligence]](Awesome-Embodied-VLAs.md)

## Contribution Guidelines

2. Propose resource supplement suggestions or point out errors via Issues;
3. Suggest new classification directions or optimize the existing structure.
